# 残業出口

残業後のオフィスビルを舞台にした、8番出口ライクな間違い探しゲーム（ローポリ・ブラウザ製）。

## 遊び方

`index.html` をブラウザで開くだけ（Three.js は CDN から読み込むのでネット接続が必要）。

- 異変を見つけたら **引き返す**（後ろの扉へ）
- 異変がなければ **先へ進む**（奥の扉へ）
- 間違えたら 8F からやり直し、1F まで降りれば退勤
- 8F は必ず「いつもの廊下」なので、ここで普段の様子を覚える

操作: クリックで視点固定 / WASD・矢印で移動 / マウスで視点 / Shift で早歩き
スマホ: 左半分ドラッグで移動、右半分ドラッグで視点

1周（8F→1F）はノーミスで約1〜2分。

## 異変の追加・確認

- 異変の一覧は `index.html` の `ANOMALIES`、見た目の変化は `buildLevel()` 内の `A('異変ID')` 分岐
- `index.html?a=異変ID` で開くと、タイトル背景にその異変を出した状態で確認できる
- 出現率は `ANOMALY_RATE`（既定 0.6）
